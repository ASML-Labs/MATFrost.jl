# MATFrost.jl

MATFrost embeds Julia in MATLAB. Julia functions define the interface, while
MATFrost converts supported values between MATLAB and Julia.

Start with [Getting Started](@ref), then see [Calling Julia](@ref),
[Data Conversion](@ref), and [Julia Object Handles](@ref).
